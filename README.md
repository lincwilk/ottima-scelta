# Ottima Scelta

Website ufficiale di Ottima Scelta.

## Struttura

Questo repository sarà la fonte principale del codice del sito web.

- `index.html` — pagina principale
- `style.css` — stile del sito
- `script.js` — interazioni
- `images/` — immagini del progetto

## Deploy

Il progetto sarà collegato a Cloudflare per la pubblicazione online.

## Nota

La versione pubblicata in precedenza su Cloudflare (`dawn-mud-70e8`) è considerata una versione di test. La versione di questo repository sarà la versione ufficiale del progetto a partire dalla configurazione del nuovo deploy.
